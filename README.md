## Вы можете менять ветки в репозитории чтобы увидеть другие задания.

Каждая ветка отдельный урок.

- **lesson№1** => Ввод-вывод и базовые переменные.
- **lesson№2** => float, int и арифметические операции
- **lesson№3** => Логические и условные операторы
- **lesson№4** => Циклы while и for
- **lesson№5** => Строки
- **lesson№6** => Списки
- **lesson№7** => Множества
- **lesson№8** => Словари
- **lesson№9** => Функции
- **lesson№10** => Двумерные списки
- **lesson№11** => Рекурсия
- **lesson№12** => ООП
- **lesson№13** => Классы и объекты
- **lesson№14** => Игра
